# 暗格 · 前端和后端参考

这是我们家 iOS app（SwiftUI）和后台（FastAPI）里暗格那几块的脱敏摘录。**跑不起来**：网络层、鉴权、
把消息递给 AI 的那一步都换成了占位。拿去喂给你们家的 AI，让它照着改进你们自己的前端和后台。

CLI `room` 和两个钩子在仓库根目录（[`../room`](../room)），这里的后端跟它共用同一个 sqlite 库。

## 文件

| 文件 | 管哪一块 |
|---|---|
| `server/room_api.py` | 后端：看卡、往暗格里加、点签跟消息一起记数、把 AI 的通知落成正中卡 |
| `app/RoomSheet.swift` | 屋卡：十类清单、「给她／给 AI」两颗、挂小签、加一样（偷偷加可以写一句来历） |
| `app/PendingRoomItem.swift` | 小签挂在输入框上、跟消息一起发；消息行画卡；会话列表预览 |
| `app/RoomEventCard.swift` | 聊天页正中的暗色小卡，以及记号的解析 |

## 一条链怎么走

**她这边点一样**

1. 屋卡 `GET /room/card` 拉清单（AI 藏的看不见；她自己藏的签上有个小粉点）
2. 点一样 → 要分给谁的先亮「给她」「给 AI」两颗 → 挂成输入框上方的小签「眼罩 → AI」，最多 6 枚
3. 她打完字按发送 → `POST /chat/send` 带 `room_items: [{item, room, to}]`
4. 后端先查重（同一个 client_msg_id 不记两次），再 `take_for_message` 一个事务全记：缺一样整单回滚
5. 存进聊天的正文：开头几行记号 `[[room:her|...]]`，后面是她的字 → app 画成正中卡 + 她的气泡
6. 递给 AI 的那句：`[房间] 她穿了「X」 ｜ 她的字`；一晚第一次点，整张卡跟着递过去

**AI 那边用一样**

1. AI 敲 `room 用 X 一句字`（CLI，记数、亮出它藏的）
2. CLI 把一行字喂给 `ROOM_NOTIFY_CMD`：`AI 给她穿了「X」 · surprise` + 下一行那句字
3. 把 `ROOM_NOTIFY_CMD` 指到 `POST /room/notify` → 后端翻成 `[[room:ai|...]]` 记号，落一条 AI 的消息
4. app 拉到这条消息 → 画正中卡，AI 现写的那句字在卡里

**她往暗格里加**

`POST /room/add {category, name, secret, desc}`：明着加的当场递一行给 AI；偷偷加的不吱声，desc 可以带一句来历
（它从哪儿长出来的、留给什么时候），存成描述第一行，她第一次点亮出来时自动删掉，之后只留物。

## 记号行合同

```
[[room:WHO|VERB|NAME|CATEGORY|SURPRISE]]
```

- `WHO`：`her` 或 `ai`，别的一律不认
- `VERB`：成品动词，app 照抄不拼，比如 `穿了`、`给AI用了`、`给她穿了`、`想玩`
- `NAME`：物件名
- `CATEGORY`：分类，可以空着
- `SURPRISE`：`1`＝藏着的东西第一次用，卡上出 surprise；`0`＝平常

只放在正文开头，一行一个，可以连着好几行。字段里的 `|` `[` `]` 换成全角、换行换空格（两头各有一份一字不差的 clean）。
解析失败的那一行起全当普通文字，不崩、不吞字。

## 要守住的几条

- 对方藏的东西，卡上、报错、模糊提示、撞名都不许漏出来（撞名只说「这个名字用不了，换一个」）
- 记数在「真发出去」那一刻，不在点签那一刻；查重之后才记
- 物件名是私密的：日志只记错误类型；会话列表预览里，记号那几行一律换成「屋里来了一样东西」（后面她自己打的字照常显示），推送不带正文
- 分类单只放一处：前端「加一样」的格子从 `/room/card` 的 `categories` 拿，别在 app 里写死
