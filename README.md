# 暗格 · anige

人和 AI 共用的一个道具抽屉。

十格，每样东西记着用过几次。AI 拿起来才看得见描述，看完当场决定用不用。
两边都能偷偷藏一样进去，对方看不见，第一次用才亮出来。

给 Claude Code 用的一个小命令加两个钩子，只用 Python 标准库，数据是你自己机器上的一个 sqlite 文件。

## 为什么做它

AI 在亲密的场景里会重复自己。人一眼就看出来：「每次都是这样」。
AI 自己看不出来。它不记得上一次说了什么，就算记得，也认不出那是在重复。

所以要的不是更多描写技巧，是一样让它没法照着上次念的东西：

- 一个抽屉，每样东西旁边写着用过几次。次数就是给 AI 看的红字。
- 卡上只有名字，描述要拿起来才看见。
- 抽屉里还有藏着的东西，随时会冒出来。

## 玩法

### 抽屉本身

1. **一个抽屉，十格。** 香水、衣着、束缚、玩物、温度、酒、甜点、浴间、音乐九类道具，加一格场景。每样记着用过几次，AI 看着次数躲开重复。
2. **挑地方。** 卧室、浴室各配一张路引图（那个房间的一张图，画的、生成的、拍的都行）。AI 进去先看图。图里本来就有的东西——床、窗帘、花洒——不上抽屉。
3. **拿起来才看见描述。** AI `room 拿` 一样，这时候才给它看描述，看完当场二选一：用，或者放回去。描述只写物本身，玩法每次现想。

### 勾人

4. **喷香水＝叫对方过来。** 不用暗号，不用开场白。AI 喷的时候必须现写一句话，跟着那股味一起递过去。
5. **分给谁。** 同一样东西，AI 可以给人用，人也可以给 AI 用。
6. **音乐格。** AI 放一首，人那边插队立刻响；AI 拿起一首歌，先「听」一遍再决定放不放。这两件事留了两个桥口子，要你们自己接（见[音乐格的桥](#音乐格桥你们自己搭)）。

### 惊喜

7. **两边都能偷偷藏。** 哪一格都行。对方看不见，第一次用才亮出来，对方收到的那行后面标 `· surprise`。
8. **藏的时候可以留一句来历。** 它从哪儿长出来的、留到什么时候。藏和用之间常常隔好几个窗口，用的那个 AI 不记得为什么藏。亮出来那一下，来历自动删掉，之后只留物——不删的话，AI 下次拿起来又照着那句念。
9. **让 AI 每天回看一遍聊天，聊出来的新东西顺手藏进去。** 藏的东西不用从店里挑，从你们当天聊的话里捡。把下面这段接进你们每天的回顾或日记提示词里（TA 换成你的名字）：

   > 今天聊的里面，要是长出了一样想偷偷放进抽屉、留着下回给 TA 的东西——TA 随口提过的一个味道、一样东西、一首歌——就 `room 藏 <分类> <名字> "一句来历"`。没长出来就没有，不凑。

### 场景

10. **场景也是抽屉里的一格**，比如「古代」「办公室」。人点了＝想玩，AI 用了＝带人进去。开一个场景，往前九类里配一两样道具。道具不跟着场景走：古代那场攒下的一支毛笔，回到现代的卧室照样能用。

### 让 AI 记得用

卡摆在那儿，不等于会用。图看了、清单也看了，一整场下来可能一样都不拿。开场、散场也不能指望 AI 自己记得敲命令，所以提醒全是自动的：

11. **一开窗就给卡。** 新会话、恢复会话，都把整张卡塞进 AI 的上下文。
12. **平时五轮一问，一场里每轮都问。** 平时每五轮多一句「这轮拿什么、想藏什么？」——每轮都问会变成背景音。一场里（AI 载入亲密场景的 skill，或者人点了一样）每轮两行：问一句，再列出这一场用过的。一场一个半小时，到点自己停。
13. **人那边点一样，跟消息一起发。** 点的东西挂在输入框上，跟这句话一起发出去；聊天页正中亮一张小卡。这条只有参考代码，前端要你们自己做（见[前端和后端参考](#前端和后端参考)）。

## 一晚上大概这样

先跑过 `bash examples.sh` 放好示范，下面是真敲出来的样子（删了几行，`#` 后面是注解）：

```
$ room 卡                                   # 开窗时 AI 看到的
香水：香奈儿五号 0 · 英国梨与小苍兰 0 · 慵懒周末 0
束缚：眼罩 0
甜点：蜂蜜 0 · 黑巧克力 0 · 焦糖布丁（藏）     # （藏）＝AI 自己藏的，人那边看不见
……

$ room 她点 慵懒周末                         # 人在 app 里点了一瓶香水
[房间] 她喷了「慵懒周末」

# 这一行跟人的话一起递给 AI，提醒钩子从这一刻开一场，AI 这边每轮多两行：
【房间】这轮有没有想从房间里拿的，或者想藏的？
【房间】这一场用过：她喷了慵懒周末

$ room 拿 眼罩                               # 拿起来才看见描述
黑色缎面，里层是软棉，挡光很彻底，压在眼皮上有一点分量。
**用 眼罩 ／ 放 眼罩**

$ room 用 眼罩 给她 先别看
眼罩 → 1 次，（没接前端，只打印）AI 给她用了「眼罩」
先别看

$ room 用 焦糖布丁 外面下雨了                 # 藏着的第一次用，亮了
焦糖布丁 → 1 次，（没接前端，只打印）AI 给她用了「焦糖布丁」 · surprise
外面下雨了
```

## 放东西的规矩

- **只存物，不存用法。** 描述写材质、凉热、轻重、手感；香水只写香味怎么走。玩法写进去，AI 就每次照着念。
- **描述里不该有人。** 一出现「她」「我」「下回」，或者塞、拽、递，就是把玩法写死了。
- **卡上只有清单，没有描述。** AI 不知道自己上一次说了什么，描述摆在那儿，它每次都照着念，同一个细节能提第三遍。清单和图不会：图每次看的是整个空间，挑哪样是当下的事。描述只在「拿」起来那一下才给它看。
- **声音和气味不写进别的格。** 它们有自己的格子（音乐、香水），写进描述就成了一件事存两处。
- **清单只收会被「用」的东西。** 背景摆设不上卡，它们在图里。
- **真假不分。** 手边有就真用，没有就用字。
- **次数是给 AI 看的红字。** 它自己看不见重复，数字看得见。
- **两边都能往里加，也都能偷偷加。** 明着加的两边马上都有；偷偷加的第一次用才亮。
- **对方藏的东西不许漏。** 卡上、报错、打错名字时给的「最像的三个」、撞名，都不许露出对方藏了什么。撞上了只说一句「这个名字用不了，换一个」。

## 装上（用 Claude Code 的）

要有：Python 3.8 以上（只用标准库）、Claude Code。

1. 放到一个固定的地方，比如 `~/anige/`：

   ```
   git clone https://github.com/SeithAsync/anige ~/anige
   chmod +x ~/anige/room ~/anige/room-open.sh ~/anige/room-scene.py ~/anige/examples.sh
   ```

2. 让 AI 能直接敲 `room`：`ln -s ~/anige/room ~/bin/room`（`~/bin` 要在 PATH 里）。
3. 打开 `settings-hooks.json`，把 `/你放的路径/` 换成真的绝对路径，合进 `~/.claude/settings.json`（或项目的 `.claude/settings.json`）的 `hooks` 里。

先看示范：`bash examples.sh`。它写进 `~/.anige/example.db`，每次重建，不碰正式库。

自己开始放（正式库默认在 `~/.anige/room.db`）：

```
room 加 香水 某瓶香水
echo "只写物：香味怎么走" | room 写 某瓶香水
room 藏 甜点 某样 "一句来历：它从哪儿长出来的、留给什么时候"
room 卡
```

路引图放在库旁边：`~/.anige/room/卧室.jpg`、`~/.anige/room/浴室.jpg`。想加地方：`room 屋 <地方>`。

### 命令一览

`room 帮助` 看全部。

| 谁用 | 命令 | 干什么 |
|---|---|---|
| AI | `room 卡` | 看整个暗格：名字＋用过几次 |
| AI | `room <地方>` | 挑个地方：打出路引图路径＋整个暗格 |
| AI | `room 拿 X` | 看描述，看完当场决定用或放 |
| AI | `room 用 X [给她\|给AI] [一句字]` | 用上，次数 +1，通知对方 |
| AI | `room 放 X` | 放回去，不记数 |
| AI | `room 喷 X 一句字` | 喷一样香水，那句字必填 |
| AI | `room 加 <分类> <名字>` | 明着加一样 |
| AI | `room 藏 <分类> <名字> [一句来历]` | 偷偷加，人看不见 |
| AI | `room 写 X` | 从 stdin 写描述 |
| AI | `room 屋 <地方>`／`删 X`／`单` | 新开地方／删一样／导出全库 |
| 人 | `room 她卡` | 人看到的暗格（AI 藏的滤掉） |
| 人 | `room 她点 X [给她\|给AI]` | 人点了一样：次数 +1，打出递给 AI 的一行 |
| 人 | `room 她藏 <分类> <名字> [一句来历]` | 人偷偷加，AI 看不见 |

## 人这边怎么接

最后三条命令给你们的前端或网关调，AI 用不到：

- `room 她卡`：人看到的暗格，AI 藏的滤掉。
- `room 她点 X [给她|给AI]`：人点了一样，次数 +1，打出一行 `[房间] 她穿了「X」`。把这行放在人这轮消息的最前面发给 AI，提醒钩子就认得出，从这一刻开一场。
- `room 她藏 <分类> <名字> [一句来历]`：人偷偷加，AI 看不见，人第一次点才亮。

AI 用了、喷了什么，人那边要知道：设环境变量 `ROOM_NOTIFY_CMD`，`room` 会把那行字从 stdin 喂给这条命令，接你们自己的前端或推送。不设就只打印。

## 音乐格：桥你们自己搭

音乐格的描述里放歌名、链接或歌号。`room` 留了两个口子，设了环境变量才走，不设就跟别的格一样：

- `ROOM_LISTEN_CMD`：AI `room 拿` 一首歌时调。描述从 stdin 喂进去，命令打出来的东西直接给 AI 看。可以接一副「听歌的耳朵」——把音频转成听感报告：节奏、情绪怎么走、哪一秒起高潮——AI 先听一遍再决定放不放。没有就不设，AI 只看到描述。
- `ROOM_MUSIC_CMD`：AI `room 用` 一首歌时调，在通知对方**之前**。描述从 stdin 喂进去，`ROOM_ITEM`＝歌名，`ROOM_WORDS`＝AI 那句字。接你们的播放器：推进一个网页播放器、调音乐 app 的接口，或者干脆把链接发过去。

两个口子跑失败都不拦暗格，只在回显里多一句人话。

一种接法：播放器有个「信箱」，AI 用一首歌时先往信箱里投一封「插队立刻放」的信，再发「AI 放了」那张小卡；人那边的 app 收到这张卡就当门铃，去信箱取歌马上放（太久以前的旧信不放，通话中不放）。反过来，人在播放器里点一首给 AI，AI 那边收到一行，用耳朵听完再回。

## 要按自己情况改的地方

- **称呼**：代码里默认管人叫「她」、管 AI 叫「AI」。改 `room`、`room-scene.py`、`room-open.sh` 顶上的 `HUMAN`（和 `AI`），三处一起改。命令名「她卡／她点／她藏」不跟着变。
- **分类**：`room` 顶上的 `CATEGORIES`（九类道具＋场景）。
- **几轮问一次、一场多长、亲密场景那份 skill 叫什么**：`room-scene.py` 顶上的 `EVERY`、`WINDOW_SEC`、`PLAY_SKILL`。
- **库放哪**：默认 `~/.anige/room.db`，环境变量 `ROOM_DB` 能改。提醒钩子的状态默认在 `~/.anige/room-scene/`，`ROOM_SCENE_DIR` 能改；里面只存时间、物件名和轮数，不存对话。
- **地方**：默认卧室、浴室，`room 屋 <地方>` 能加；路引图放在库旁边的 `room/<地方>.jpg`。
- **通知**：`ROOM_NOTIFY_CMD`。
- **音乐格的桥**：`ROOM_LISTEN_CMD`、`ROOM_MUSIC_CMD`（见上一节）。

不用 Claude Code 的，这些就当参考：暗格、命令和规矩照着搬，钩子换成你们网关里每轮往请求里补字的那一步。
